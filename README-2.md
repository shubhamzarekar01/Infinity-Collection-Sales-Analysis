# 📊 Infinity Collection - B2B Business Data Analytics Project

## 📈 Executive Summary
This project presents an end-to-end Data Analytics solution built on a real-world B2B Footwear and Bag Wholesale business with an annual turnover of ₹1.5 Crores. Due to a physical recovery phase after a major accident, I transitioned my field-sales operations into an automated, data-driven system. This project demonstrates how I use data to optimize business performance remotely.

---

## 🛠️ Tech Stack & Skills Demonstrated
* **Data Cleaning & Manipulation:** Python (Pandas, NumPy)
* **Database Management & Querying:** MySQL (Relational DB, Ledgers, JOINs)
* **Data Visualization & Dashboarding:** Power BI (Interactive Reports)
* **Business Analytics:** YoY Growth, Sales Forecasting, Customer Lifetime Value (CLV), Supplier/Customer Ledger Automation.

---

## 🚀 Key Insights & Business Impact
1. **Sales Analysis (`analysis.py`):** Used Python to clean and merge monthly sales data from 2024 and 2025 to identify seasonal trends and high-performing categories.
2. **Database Schema (`infinity_collection_schema.sql`):** Created a relational database to track customer and supplier transactions, reducing outstanding dues through automated tracking.
3. **Power BI Dashboard (`dashboard.jpg`):** Built a visual dashboard to track sales metrics, profit margins, and financial health on autopilot.
